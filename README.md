# AI Wiring Studio

一个面向**模拟电路板接线设计**的 Windows 桌面应用：在画布上摆放元件、引脚对引脚连线，并做**确定性的电气规则检查（ERC）**。可选地借助你自己的 AI 接口，把文字描述、型号、网页资料或图片快速转成候选元件资料。

- 技术栈：Tauri 2 + Rust（后端）／ React + TypeScript + Vite（前端）／ React Flow（画布）
- 平台：Windows x64
- 版本：0.1.0

> 说明：软件只做**规则检查**，不做电路仿真，也不做电流预算估算；算不出来的量一律显示「未知」，绝不猜测。

## 主要功能

- **画布设计**：元件拖放、引脚级连线、连线途经点、自动走线、缩放与网格。
- **元件库与编辑器**：自建元件定义（引脚、电气参数、封装尺寸、图片）；独立于项目文件的用户元件库，可跨项目复用。
- **线路组织**：线路分类（用途）、筛选、聚焦（高亮当前网络）、显示态持久化。
- **电气规则检查（ERC）**：短路、电源冲突、过压、输出冲突、极性错误、电平不匹配、悬空/重复连线、必接输入未连接等，结果按「明确错误 / 风险警告 / 待确认 / 优化建议」四级分类；检查器内如实声明「检查范围」（见下文）。
- **接线代码（Wiring Code v1）**：文本化的接线描述导入/导出，可据此补查缺失元件定义。
- **项目文件**：`.aiws` 项目保存/打开，原子写入 + 自动备份。
- **AI 元件资料导入（可选）**：支持文字描述、型号、网页链接、图片、接线代码补查；AI 输出只作为**候选**，必须经你人工确认为准。
- **外观设置**：界面强调色、画布/连线/元件/界面底色，用户设置优先且可持久化。

## 安装

1. 从 Releases 下载 `AI Wiring Studio_<版本>_x64-setup.exe`。
2. 运行安装程序（NSIS）；默认安装到用户目录，无需管理员权限。
3. 校验安装包完整性：见 Release 页面附带的 SHA-256。

应用**不需要联网即可使用**除「AI 元件资料导入」以外的全部功能。

## 从源码构建

前置：Node.js、Rust 工具链（含 `cargo`）、Windows 上的 Tauri 2 构建依赖。

```powershell
npm install
npm run tauri build
```

常用校验命令：

```powershell
npm run lint           # TypeScript 类型检查
npm test               # 单元测试（Vitest）
npm run test:e2e       # 端到端测试（Playwright）
npm run benchmark      # 领域层性能基准
cargo test --manifest-path src-tauri/Cargo.toml
```

## AI 配置与隐私

- **API Key 存放位置**：密钥只写入 **Windows 凭据管理器（Credential Manager）**，由 Rust 后端读写。它**不会**写入项目文件（`.aiws`）、用户元件库或日志，也**不会**进入前端 JavaScript。
- **数据发送范围**：只有在你主动使用「AI 元件资料导入」时，软件才会向**你自行配置的接口地址**发起请求（OpenAI 兼容的 `/chat/completions`）。发送内容仅为你提供的材料：文字描述、型号、网页正文，或图片（以 data URL 形式）。项目结构与用户元件库不会外发。
- **接口地址限制**：真实服务必须使用 `https`；仅本机回环地址（`localhost` / `127.0.0.1`）允许 `http`，便于本地网关与测试。
- **错误信息**：调用失败时，错误信息中的密钥会被强制脱敏，不会回显。
- **离线可用**：不使用 AI 导入时，应用完全离线运行。

## 检查器能力边界

软件在检查器内如实声明以下五层能力，绝不暗示做过它没做的事：

| 层级 | 状态 | 说明 |
| --- | --- | --- |
| 连接检查 | 已检查 | 悬空线、引脚不存在、重复连接、必接输入未连接 |
| 电气规则检查 | 部分检查 | 短路、电源冲突、过压、输出冲突、极性错误；电平匹配仅在引脚填了输入电平范围时判断 |
| 系统预算检查 | 不在当前范围 | 缺负载模型，无法计算电流与供电容量；算不出的项显示「未知」 |
| 工程建议 | 部分检查 | 仅依据已确认引脚角色的少量条件提醒，不引入通用规则库 |
| 仿真分析 | 不在当前范围 | 只做规则检查，不做电路仿真 |
